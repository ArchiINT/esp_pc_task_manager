# ESP32-S3 PC Monitor

Монитор состояния ПК на ESP32-S3 + IPS ST7789 240×240. Агент на компьютере
собирает телеметрию (аптайм, CPU, RAM, NVIDIA GPU) и отдаёт её на плату по USB
или BLE; плата рисует четыре страницы на LVGL.

```
  PC                                     ESP32-S3
 ┌──────────────────────┐               ┌───────────────────────────────┐
 │ pcmon_agent.py       │  USB CDC      │ pcmon_link  → pcmon_ui        │
 │  psutil + NVML       │ ─────────────→│  (декодер)    (LVGL, 4 стр.)  │
 │  10 кадров/с, 73 Б   │  или BLE NUS  │                    ↓          │
 └──────────────────────┘               │ pcmon_display → ST7789 SPI    │
                                        └───────────────────────────────┘
```

## Подключение дисплея

Значения по умолчанию совпадают с распиновкой из твоего проекта
`~/esp/esp-idf-st7789`, так что перепаивать ничего не нужно. Любой пин можно
поменять в `idf.py menuconfig` → **PC Monitor: display (ST7789)**.

| Дисплей ST7789 | ESP32-S3 | Примечание |
|----------------|----------|------------|
| `GND`          | `GND`    | |
| `VCC`         | `3V3`    | **только 3.3 В**, от 5 В модуль сгорит |
| `SCL` / `SCK`  | `GPIO1`  | SPI CLK |
| `SDA` / `MOSI` | `GPIO2`  | SPI MOSI |
| `RES` / `RST`  | `GPIO3`  | сброс панели |
| `DC` / `A0`    | `GPIO4`  | команда/данные |
| `CS`           | `GPIO5`  | если у модуля нет CS — посадить на GND и указать `-1` |
| `BLK` / `LED`  | `GPIO6`  | ШИМ-яркость; можно посадить на 3V3 и указать `-1` |
| —              | `GPIO0`  | кнопка BOOT: смена страницы (long press — автолистание) |

Плата питается и прошивается по тому же USB-кабелю, по которому идёт
телеметрия. Логи ESP-IDF выведены на UART0 (GPIO43/44), чтобы не мешать
бинарному потоку данных на USB.

## Сборка и прошивка

```bash
. ~/esp/esp-idf/export.sh
cd ~/esp/esp_pc
idf.py build                      # target esp32s3 уже выставлен
idf.py -p /dev/ttyACM0 flash
```

Сборка уже проверена: образ 685 КБ, свободно ~113 КБ DRAM.

Если `/dev/ttyACM0` недоступен без sudo (Arch):

```bash
sudo usermod -aG uucp $USER      # затем перелогиниться
```

`idf.py monitor` по USB запускать не нужно: этот порт занят телеметрией,
а логи идут на UART0.

## Агент на ПК

Окружение уже создано в `host/.venv` (psutil, nvidia-ml-py, pyserial, bleak):

```bash
cd ~/esp/esp_pc/host
.venv/bin/python pcmon_agent.py            # автопоиск порта, 10 Гц
.venv/bin/python pcmon_agent.py --once     # разовый снимок без платы
.venv/bin/python pcmon_agent.py --rate 20  # чаще обновления
.venv/bin/python pcmon_agent.py --list-ports
```

Проверка на твоём железе (`--once`):

```
cpu       : AMD Ryzen 5 5600XT 6-Core
gpu       : GeForce RTX 5060 Ti
cpu load  : 1.3%  @ 2497 MHz  (12 threads)
cpu temp  : 34.0 C            (k10temp/Tctl)
ram       : 5279 / 31977 MiB
gpu temp  : 30.0 C, 6.5 W, VRAM 894 / 16311 MiB
frame size: 73 bytes
```

Автозапуск: `host/pcmon-agent.service` — user-юнит systemd, инструкция внутри
файла.

## Страницы

Переключение — кнопкой BOOT (GPIO0) или автоматически раз в 12 с
(долгое нажатие включает/выключает автолистание).

1. **OVERVIEW** — две дуги CPU/GPU с температурами, полосы RAM и VRAM, частота
   CPU и потребление GPU.
2. **CPU** — большая дуга загрузки, частота, температура пакета и по столбику
   на каждый логический поток.
3. **GPU** — загрузка, температура, частота, мощность, VRAM, обороты вентилятора.
4. **HISTORY** — график загрузки CPU и GPU за последнюю минуту.

В шапке всегда видны индикатор связи, имя хоста и аптайм ПК. Если агент не
отвечает дольше 3 с, поверх страницы появляется «WAITING FOR HOST», а последние
значения остаются на месте.

Интерфейс английский: встроенные шрифты LVGL Montserrat не содержат кириллицы,
а тащить свой шрифт ради подписей — лишние килобайты во флеше.

## Вариант с Bluetooth

ESP32-S3 поддерживает только BLE (Bluetooth Classic/SPP там нет), поэтому
используется Nordic UART Service — его понимает любой десктопный стек.

```bash
rm -f sdkconfig                    # иначе прежний выбор транспорта останется
idf.py -D SDKCONFIG_DEFAULTS="sdkconfig.defaults;sdkconfig.defaults.ble" \
       fullclean build flash
cd host && .venv/bin/python pcmon_agent.py --transport ble
```

USB остаётся рекомендуемым вариантом: задержка меньше миллисекунды, нет
спаривания, и кабель всё равно нужен для питания.

## Задержка и нагрузка

| Этап | Время |
|------|-------|
| период выборки на ПК | 100 мс при 10 Гц (`--rate` меняет) |
| передача 73 Б по USB CDC | < 1 мс |
| разбор кадра на плате | единицы микросекунд |
| перерисовка LVGL | ≤ 16 мс (перерисовываются только изменившиеся области) |

Трафик — около 730 Б/с. SPI по умолчанию 40 МГц (безопасно для проводков-
«дюпонтов»); при коротких проводах в menuconfig можно поднять до 60–80 МГц.

## Протокол

Кадр: `A5 5A | ver | type | len | payload | crc16`, CRC-16/CCITT-FALSE по
`ver..payload`, little-endian. Декодер потоковый и пересинхронизируется, если в
поток попадёт мусор.

Дробные величины передаются целыми: `*_pm` — промилле (÷10 = %), `*_dc` —
десятые градуса, `*_dw` — десятые ватта. Поле `flags` помечает, какие
необязательные значения реально измерены (`N/A` вместо выдуманного нуля).

Определения обязаны совпадать в двух местах:
`components/pcmon_proto/include/pcmon_proto.h` и `host/pcmon/protocol.py`
(размеры проверяются `_Static_assert` и `assert` при импорте).

## Если что-то не так

| Симптом | Что сделать |
|---------|-------------|
| Белый/чёрный экран | Проверить `RES`, `DC`, `CS` и питание 3.3 В; поднять яркость (`PCMON_LCD_BRIGHTNESS`) |
| Цвета как негатив | Выключить `PCMON_LCD_INVERT_COLOR` |
| Изображение зеркальное/повёрнуто | `PCMON_LCD_MIRROR_X/Y`, `PCMON_LCD_SWAP_XY` |
| Картинка сдвинута на несколько пикселей | `PCMON_LCD_X_GAP` / `Y_GAP` (частая история: 240×240 на кристалле 240×320) |
| Полосы, мусор на экране | Снизить `PCMON_LCD_PIXEL_CLOCK_MHZ` до 20–26 МГц |
| Висит «WAITING FOR HOST» | Агент не запущен, не тот порт (`--list-ports`), или нет прав на `/dev/ttyACM0` |
| Нет температуры CPU | `sensors-detect`, модуль `k10temp` (для Ryzen); агент напишет, какие сенсоры видит |
| GPU показывает `N/A` | `nvidia-ml-py` не установлен или драйвер NVIDIA не загружен |
